01

Executive summary: the dual-pillar thesis

Why ordinary API authorization fails when autonomous personal agents take consequential real-world actions.

Traditional authorization answers: "Who is calling this API?"

IntentGate answers the missing business question: "What did the human user actually authorize this agent to do, under which exact financial and temporal conditions, and is this specific action still within those bounds?"

In the emerging Agentic Era (2026+), personal AI assistants (e.g., Instinct AI on WhatsApp, OpenAI Dots in ChatGPT, Meta Muse across messaging, and Claude Computer Use) are transitioning from conversational information retrieval to executing real-world transactions: booking appointments, purchasing tickets, ordering tests, reserving inventory, and processing payments.

The Foundational Product Division

This product is built on two interdependent, defensible layers:
1. AgentFlow (Merchant-Facing OS): Turns traditional startup APIs into stateful, discoverable, safe business capabilities (Holds, Sagas, Idempotency, SLAs, and Readiness Badges).
2. IntentGate / IntentOS (User & Agent Policy Layer): Compiles user conversation into cryptographically signed mandates, enforces agent identity (DIDs), catches scope drift, and manages human confirmation gates.

02

Why this idea & why it is critically important

The structural vulnerability of exposing raw REST APIs to probabilistic software agents.

Every prior generation of API security was designed for deterministic software clients with static permissions (OAuth 2.0 scopes, Bearer tokens, API keys). These credentials grant binary technical access, not contextual semantic authority.

When an autonomous agent operates with static technical credentials, standard failure modes immediately materialize:

1. The Silent Retry Storm

During a 5.1s network timeout, an agent automatically retries POST /bookings. Without distributed idempotency, the merchant database creates duplicate reservations and charges the customer’s card twice.

2. Scope Drift & Upselling

A user instructs: "Compare flight tickets." The agent identifies a flight, encounters an upsell screen, and executes POST /insurance-addon for ₹1,200. The agent was technically authenticated, but acted outside the user's intent.

3. Orphaned Inventory Locks

An agent reserves a medical slot. The agent crashes, hits a rate limit, or waits for user feedback. Standard APIs lack automatic Time-to-Live (TTL) hold release, locking merchant capacity indefinitely.

4. The Impersonator Bot Risk

Without verifiable cryptographic agent identity, rogue scripts or prompt-injected bots can replay tokens, spoofing reputable personal assistants like Instinct or Dots to drain user balances.

The Core Importance

Without AgentFlow and IntentGate, startups cannot safely open machine endpoints to the agentic web without incurring chargebacks, database corruption, and catastrophic inventory loss.

04

AgentFlow in depth: the merchant capability OS

How AgentFlow converts fragile internal APIs into resilient, policy-governed business verbs.

AgentFlow is installed as a gateway proxy in front of a startup's existing backend (or as a lightweight middleware SDK). Instead of exposing raw database CRUD operations, it wraps them into a Managed Business Capability:

1. Business Capability Synthesizer

Ingests existing OpenAPI specifications and wraps 4–5 disjointed endpoints into a single transactional state machine:

Available → Held (10m TTL) → Confirmed → Cancelled
2. Universal Idempotency Shield

Backed by distributed Redis lock managers. If an agent network lags and retries 3 times, the shield intercepts duplicates and returns the cached confirmation with zero duplicate debits.

3. Inventory Hold Engine (10m TTL)

Permits non-destructive reservation of slots without immediate debit. An internal distributed timer automatically releases held resources back to inventory if confirmation is not received within 600s.

4. Chaos Simulation Test Harness

An automated adversarial testing suite that bombards the startup’s staging API with 50+ agentic failure scenarios (burst retries, race conditions, parameter fuzzing) before going live.

5. Capability Readiness Certification

Generates a cryptographically signed readiness badge and public machine-readable manifest (/.well-known/agent-capability.json) that agent discovery registries index with trust scores.

6. Protocol Exporters (MCP & A2A)

Dynamically serves capabilities over Anthropic Model Context Protocol (MCP JSON-RPC/SSE) and Linux Agent-to-Agent (A2A) endpoints without changing backend application code.

05

IntentGate in depth: the intent authorization layer

The policy engine translating human natural language into verifiable, drift-proof machine mandates.

IntentGate sits as the security perimeter between the user's personal agent and the external world. It ensures that an agent cannot exceed the precise mandate granted by the user.

1. Natural-Language Intent Compiler

Converts conversational prompts ("Book me a dental cleaning under ₹1,500 this Friday...") into an immutable JSON execution mandate with bounded parameters, allowed actions, and expiry.

2. Cryptographic Agent Identity (DID-Agent)

Issues decentralized identifiers (did:agent:instinct:...) with model weight hardware attestation. Requires cryptographic Proof-of-Possession (PoP) signatures on all requests.

3. Runtime Intent Drift Firewall

Executes live semantic vector evaluation on incoming tool arguments. If an agent attempts an upsell or parameter outside original intent, the firewall returns HTTP 403 IntentDriftDetected.

4. Tiered Confirmation Manager

Low-risk operations (search availability, 10m temporary hold) execute automatically. High-risk actions (payment debits, cancellations, legal signoffs) trigger biometric human approval.

5. Single-Use Execution Tokens

Upon human approval, IntentGate generates an ephemeral, single-use token tied strictly to provider ID, slot ID, and exact price. Stolen or hallucinated tokens cannot be re-used.

6. Multi-Leg Compensating Rollback Sagas

If an agent coordinates a multi-step workflow (e.g. clinic booked, but diagnostic test fails), IntentGate coordinates automatic compensating rollbacks, releasing holds and returning credits.

07

Granular end-to-end user & agent execution flow

Step-by-step lifecycle from natural language prompt to safe settlement and audit record.

1
User Prompt & Intent Mandate Compilation

User instructs their assistant (Instinct/Dots): "Find me a physiotherapist this week under ₹2,000. You may search and hold a slot, but ask me before booking." IntentGate compiles this prompt into an immutable execution mandate with max_budget: 2000, allowed: ["search", "hold"], and requires_confirmation: ["confirm_booking"].

2
Agent DID Attestation & Discovery

The personal agent signs the request with its private key (did:agent:instinct-09:...). IntentGate validates agent attestation and routes to the AgentFlow Gateway discovering verified clinic endpoints.

3
Low-Risk Temporary Hold Execution

Agent invokes hold_slot(provider='PhysioCare', time='Friday 4pm', price=1800). Because "hold" is pre-authorized in the mandate, IntentGate permits execution. AgentFlow locks the clinic slot for 10 minutes (TTL 600s).

4
Intent Drift & Confirmation Intercept

Agent prematurely attempts confirm_booking. IntentGate intercepts: operation requires explicit human confirmation. Concurrently, if the agent attempted an unprompted add-on (e.g. purchase_massage_oil: 500), IntentGate blocks it with 403 IntentDriftDetected.

5
Human Biometric Handshake & Ephemeral Token

IntentGate prompts the user via push notification: "PhysioCare slot held for ₹1,800 on Friday 4 PM (8 mins left). Confirm booking?" The user approves via FaceID/fingerprint. IntentGate issues a single-use execution token valid for exactly 180 seconds.

6
Idempotent Settlement & Dual-Signed Notary Receipt

AgentFlow invokes the merchant backend with the single-use token and universal idempotency key. Funds are settled via payment connector. A dual-signed cryptographic receipt is recorded on the tamperproof audit ledger. If the agent retries on network lag, AgentFlow returns the cached receipt with 0 duplicate debits.
